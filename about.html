From a first sketch

I’m Jason Nwezeh-Onuh Jeremiah, a cross-platform and full-stack software developer and the founder and CEO of N.O Group. I take complex software projects from conceptual UI/UX design through to production deployment and native Windows desktop packaging—connecting product thinking, thoughtful interfaces and dependable engineering.

My work spans high-performance cross-platform mobile applications built with Flutter and Dart, responsive web experiences and native Windows desktop software. I’m comfortable moving between the visible details of a user interface and the data, cloud services and automation that make a product work beyond the screen.

Recent work includes MFSL Office, a custom enterprise inventory and management application built for M-Tek Fire & Safety Ltd. in Kaduna.

Based in Kaduna, Nigeria, I’m available for freelance projects and contracts with teams looking for a considered, end-to-end approach.
